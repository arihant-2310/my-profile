# my profile

Personal site of Arihant Hirawat: a single static page (plain HTML and CSS, a little vanilla JavaScript, no build step).

## Preview locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Layout

- `index.html` – all content
- `CSS/styles.css` – styles, including light/dark themes and responsive breakpoints
- `images/` – avatar, link-preview image and touch icon
- `favicon.ico` – browser tab icon

## Notes

- Client names are intentionally anonymised.
- `images/og-image.jpg` is the link-preview card; regenerate it if the headline or avatar changes.
